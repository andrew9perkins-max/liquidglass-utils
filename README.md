# Liquid Glass Utils

This repository contains the source for Liquid Glass Utils — a client-side Fabric mod for Minecraft 1.21.11 that adds a gorgeous macOS "Liquid Glass"-styled dashboard and a collection of lightweight utilities.

Install
- Drop the built jar into your .minecraft/mods folder alongside Fabric API and Fabric Loader for Minecraft 1.21.11.

Build
- Requires JDK 21. Build with: ./gradlew build

Initial scaffold: feature/ping branch contains the project skeleton and the Ping module.
